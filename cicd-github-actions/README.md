## CI vs CD

| Aspect | CI (Continuous Integration) | CD (Continuous Delivery/Deployment) |
|--------|----------------------------|-------------------------------------|
| What | Automatically build and test code on every push | Automatically deliver/deploy to environments |
| Goal | Detect integration issues early | Always have deployable code |
| When runs | On every push/PR | After CI succeeds |
| Output | Test report + build artifact | Deployed application |

---

## GitHub Actions Concepts

### Workflow
A YAML file in `.github/workflows/` that defines automated CI/CD processes.
Triggered by events (push, PR, schedule, manual).

### Jobs
A workflow contains jobs. Jobs run in parallel by default (or sequential with `needs:`).

### Steps
Each job has steps - individual commands or actions that run in sequence.

### Runners
Virtual machines that execute jobs. GitHub provides hosted runners (ubuntu-latest, windows-latest, macos-latest). You can also self-host.

### Secrets
Encrypted environment variables stored in GitHub repo settings. Used for API keys, passwords, Docker Hub credentials.

### Artifacts
Files generated by a workflow that can be uploaded/downloaded between jobs (build outputs, test reports).

## Complete CI/CD Pipeline Demo

### Project Structure
```
cicd-demo/
  app.py             # Flask application
  test_app.py        # Unit tests
  Dockerfile         # Container image
  requirements.txt   # Python dependencies
  .github/
    workflows/
      ci.yml         # CI pipeline
      cd.yml         # CD pipeline
```

### Application (app.py)
```python
from flask import Flask
app = Flask(__name__)

@app.route("/")
def hello():
    return "Hello World from CI/CD Pipeline!", 200

@app.route("/health")
def health():
    return {"status": "ok"}, 200

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

### Dockerfile
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]
```

### CI Pipeline (.github/workflows/ci.yml)
```yaml
name: CI Pipeline

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-test:
    name: Build and Test
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v4

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: "3.11"

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Run unit tests
      run: |
        python -m pytest test_app.py -v

    - name: Build Docker image
      run: |
        docker build -t cicd-demo:${{ github.sha }} .

    - name: Upload test results
      uses: actions/upload-artifact@v3
      if: always()
      with:
        name: test-results
        path: test-results.xml
```

### CD Pipeline (.github/workflows/cd.yml)
```yaml
name: CD Pipeline

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    name: Deploy to Docker Hub
    runs-on: ubuntu-latest
    needs: build-and-test

    steps:
    - uses: actions/checkout@v4

    - name: Login to Docker Hub
      uses: docker/login-action@v3
      with:
        username: ${{ secrets.DOCKERHUB_USERNAME }}
        password: ${{ secrets.DOCKERHUB_TOKEN }}

    - name: Build and push image
      uses: docker/build-push-action@v5
      with:
        push: true
        tags: |
          ${{ secrets.DOCKERHUB_USERNAME }}/cicd-demo:latest
          ${{ secrets.DOCKERHUB_USERNAME }}/cicd-demo:${{ github.sha }}
```
